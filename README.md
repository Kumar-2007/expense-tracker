
# Expense Tracker App

## Project Overview
Expense Tracker is a beginner-friendly Android application developed using Flutter and Dart.

The application helps users manage their daily expenses, track spending, and view category-wise expense summaries.

## Objectives
- Record daily expenses.
- Manage expenses easily.
- Calculate total expenses.
- Display category-wise spending.
- Store expense data on the device.

## Technologies Used
- Flutter
- Dart
- Provider
- ChangeNotifier
- SharedPreferences

## Main Features
1. Add new expenses.
2. View all transactions.
3. View expense details.
4. Edit and delete expenses.
5. View category-wise summaries.
6. Save data locally.
7. Validate user input.

## Expense Categories
- Food
- Travel
- Shopping
- Education
- Bills
- Other

## Application Screens
1. Dashboard Screen
2. Transactions Screen
3. Add Expense Screen
4. Expense Details Screen
5. Category Summary Screen

## Installation and Execution

1. Install Flutter SDK.
2. Clone this repository.
3. Open the project folder.
4. Run the following command:

   flutter pub get

5. Start the application:

   flutter run

## Testing

Run the following command:

flutter test

## Build APK

flutter build apk --release

APK Location:

build/app/outputs/flutter-apk/app-release.apk
